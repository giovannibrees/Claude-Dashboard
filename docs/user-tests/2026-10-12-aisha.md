# User test: Aisha (24, IT average, phone, English second language)
Date 2026-10-12 · app http://localhost:8099/ (sample data) · 390x844 touch, 2x · Playwright/Chromium

Goals: approve a batched question with per-number feedback, acknowledge a delivery, add a customer profile.

## Steps
1. Open page. Expects: what needs her. Sees: 4 counts, then "Needs you" cards. Fine. (img/aisha-1-home.png)
2. Batched question "Test cleanup: project and agent": taps Feedback. Input appears with placeholder "1 yes, 2 no, 3 use option B" and a hint. Clear. (img/aisha-2-feedback.png)
3. Types "1 no, 2 yes", taps Send. Card leaves Needs you, Need-you count 3 -> 2, card shows in Feed as answered. Works. (img/aisha-3-after-send.png)
4. Delivery "Signup flow done": taps Acknowledge. Card leaves Deliveries. Works. (img/aisha-4-ack.png)
5. Adds profile: expects a visible form. It is hidden inside "Customer profiles (0)" under each project, far down the page. Opens it, fills it, taps Add profile: "Added Aisha." and count becomes 1. (img/aisha-5..7)

## Findings
- confusing: sticky header takes about 175px (20%) of the phone screen and wraps "Agent Hub" and "Live · 06:04 PM" onto 2-3 lines; it never shrinks while scrolling.
- confusing: the profile form is only reachable by scrolling past the whole feed to the Projects block, inside a collapsed "Customer profiles" toggle labelled with a count. No link from the top.
- confusing (language): "Not picked up yet", "Not approved: the agent waits", "Release automatically when all checks pass", "Past 4 hours: the agent may proceed" are hard for a second-language reader; the answer shows no plain "sent" confirmation.
- confusing: added profile list shows needs but not goals ("Approve a batched question" is not displayed).
- idea: a "Add customer profile" shortcut near the top.
No bug or blocker: all three goals finished.
